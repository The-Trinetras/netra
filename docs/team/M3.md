# M3 — Visual and video evidence

Read [ownership](ownership.md), [current scope](../architecture/current-scope.md),
[multimedia rules](../../.claude/rules/multimedia.md),
[backend-data rules](../../.claude/rules/backend-data.md) for jobs and
[runtime baseline](../architecture/runtime-baseline.md).

**Own:** figures, diagrams, graphs, basic equations and video evidence/adapters.
Validate table extraction with M2 owning source/table storage. Preserve observed
structure separately from interpretation, estimates and unreadable details. No new
visual/video agent; no braille, sonification or specialized code-navigation work.

**Approved target:** source-linked axes/units, connectivity, headers/cells, equation
grouping and exact video intervals. Use known player time with M5; pause the lecture
while explaining and return to that position. YouTube discovery/selection remains
in scope. Playback access and analysis permission/technical readiness are independent
checks; transcript-only access does not prove visual understanding.

**Current source evidence:** [evidence.py](../../api/src/netra_api/multimedia/evidence.py)
distinguishes observation sources; [video models](../../api/src/netra_api/multimedia/video/models.py)
and [timestamps](../../api/src/netra_api/multimedia/video/timestamps.py) define locations.
[VideoEvidenceService](../../api/src/netra_api/multimedia/video/service.py) is a protocol.
[Twelve Labs adapter](../../api/src/netra_api/multimedia/providers/twelve_labs.py)
and its tests do not establish account access or live media fidelity.

**Shared boundaries:** M2 source version/storage and worker ownership; M1 evidence-gap
strategy; M4 validated evidence for teaching; M5 accessible exploration and playback.
Use current internal models and [shared contracts](../../shared/contracts/); missing
client playback fields require coordinated review, not invented messages. Providers
remain behind the existing adapters, without silent replacement.

**Next integration work:** permitted uploaded-video and YouTube capability checks,
table/source mapping, timestamp-to-evidence resolution and player integration.
The proposed embedded player/web-view dependency needs M5/M1 review. Provider/model
availability remains unverified; no live calls are authorized by this migration.

**AX integration:** trace media retrieval/analysis, attempts, source/time provenance
and uncertainty through M1's boundary. Supply reviewed original-media references
and error cases for M4's versioned datasets; distinguish extraction failure from
unsupported explanation. Never export raw media/signed URLs by default or accept
Alyx labels without review. Test failure/cancellation traces and correlate permitted
playback measurements with M5. Follow the [AX plan](../architecture/arize-ax-integration.md)
and [M3 prompt](prompts/M3.md); judge scores do not establish visual fidelity.

**Acceptance target:** compare the original graph axes/table rows/equation and lecture
frame to extracted evidence. Test unreadable and rejected sources, wrong timestamps,
timeouts and replay. Pair accessibility checks with M5; a text judge alone cannot
verify visual fidelity. No application checks were run here; see the
[report](../audits/documentation-migration-report.md).
