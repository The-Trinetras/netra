# M2 — Data, ingestion and retrieval

Read [ownership](ownership.md), [current scope](../architecture/current-scope.md),
[backend-data rules](../../.claude/rules/backend-data.md),
[data ownership](../architecture/data-ownership.md) and [runtime baseline](../architecture/runtime-baseline.md).

**Own:** PostgreSQL infrastructure, source/version records, PDF and supported lecture
ingestion, reading blocks, retrieval, jobs/outbox and Pinecone. Domain owners retain
their validation/write policies. M3 owns visual/table extraction semantics; M4 owns
history validation. General web, Drive and additional formats are deferred.

**Approved target:** private S3 stores source bytes; PostgreSQL owns structured truth.
Keep immutable versions, chunk-to-reading mappings and exact return positions.
Validate retrieved IDs against authoritative access/deletion/version state. Jobs
use leases, at-least-once execution, stable operation identities, retry/backoff and
outbox. Make external calls outside long transactions and handle uncertain completion.

**Current source evidence:** [source models](../../api/src/netra_api/content/sources/models.py)
and [reading blocks](../../api/src/netra_api/content/reading/blocks.py) define structures;
[retrieval service](../../api/src/netra_api/content/retrieval/service.py) and
[session repository](../../api/src/netra_api/session/repository.py) define protocols.
[Migration versions](../../api/migrations/versions/) contains only a placeholder.
Worker [runtime](../../worker/src/netra_worker/runtime/) contains scaffolding and
local logic, not evidence of complete durable execution. The
[job schema](../../shared/contracts/jobs/v1/job.schema.json) is empty.

**Shared boundaries:** coordinate identity/session persistence with M1, source/table
storage with M3, factual activity/answer/assistance schema and atomic commits with M4.
See the [boundary table](ownership.md) for authoritative paths and consumers. Do not
invent a cross-process job interface or delete legacy review/graph data to reflect
scope removal. Pinecone and Neo4j cannot overwrite truth.

**Next integration work:** concrete repositories/migrations and ingestion/retrieval;
activation gates; durable job/outbox recovery; complete factual-history storage.
M1/M2 must resolve external job-contract need and RDS/PgBouncer versus historical
Compose database placement. Dependency locks remain missing; do not resolve/install
them as part of documentation work.

**AX integration:** trace ingestion/retrieval, authoritative evidence validation
and each worker attempt through M1's shared boundary. Review internal job links,
tracing dependency compatibility and worker lifecycle; retain canonical ownership
and idempotency under export failure. Supply source/relevance fixtures to M4 and
review isolated Modal compute. AX stores derived diagnostic/experiment copies,
with reproducible artifacts retained independently. Follow the
[AX plan](../architecture/arize-ax-integration.md) and [M2 prompt](prompts/M2.md).

**Acceptance target:** source-version pinning, unauthorized vector IDs, unreadable
extraction, lease loss, worker crash, outbox replay and stale projection ordering.
Do not claim database recovery from mocked repositories. No application checks were
run here; see the [report](../audits/documentation-migration-report.md).
