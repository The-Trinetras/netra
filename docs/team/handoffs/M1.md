## Implemented behaviour

1. **Authenticated transport.** Credential verified before WebSocket accept
   (close 1008 otherwise). Every message is strictly parsed against protocol v1 and
   re-resolved by `IdentityService` (credential expiry, active account, device access,
   non-revoked account–session binding). Client binary frames close 1003. Typed
   `error` payloads with safe messages; `SESSION_VERSION_CONFLICT` carries the current
   version.
2. **Replay/version semantics.** `SessionService.handle_request`: replay lookup before
   the expected-version check; identical retransmission replays the committed text
   messages (never audio); different payload under the same `request_id` →
   `REQUEST_ID_CONFLICT`; state write + replay record commit atomically; concurrent
   identical requests produce one effect; concurrent different requests → one
   conflict. No-change commands record replay without advancing the version.
3. **Deterministic navigation** (`session/navigation.py`), no model call: stop, pause,
   continue, next/previous by unit, repeat by mode, where_am_i (text-only, no version
   change), back_to_reading, undo_jump, return_to_question (same persisted question).
   Final `turn.submit` utterances matching a command route here first.
4. **Playback.** Generation registry: one speaking generation per session; STOP,
   supersession and disconnect cancel terminally; pause/continue resume only paused
   output. Acks must name a sentence actually sent in a non-cancelled generation;
   only `completed` is persisted; only source-reading sentences from the pinned
   version move the reading position; a snapshot follows a position change.
   Synthesis checks eligibility before cache, quota and every frame; incomplete
   audio is never cached; quota failure keeps text.
5. **Bounded Coordinator loop** (`coordinator/graph.py`): shared `TurnBudget`
   (4/6/20) counted before every model call and tool dispatch (atomic batch
   reservation), timeouts capped by remaining time, cancellation abandons model,
   tool and Tutor calls with no output. Model output parsed strictly. Requirements and
   support claims are verified against validated evidence and structured observation
   provenance (unreadable → gap; generated → not observed; estimated → approximate).
   Answers/delegation require all requirements supported and cited ids validated.
   Identical repeated actions while requirements are open are refused (no-progress
   stop, not a numeric cap). Limits produce supported findings plus stated gaps.
   Trace: `tool_result → evidence_gap → action_changed → evidence_validated`.
6. **Tutor delegation** through the v1 typed handoff on the SAME budget instance;
   result validated (handoff id, cited evidence ⊆ handed evidence, awaiting-answer
   question already persisted, private correct answer absent from public segments).
   Pending question, hint count, lesson and reading return position committed through
   `SessionService.commit_turn` (merged onto the latest state) before delivery.
7. **Reconnect.** `session.resume` → canonical snapshot, then the same persisted
   `quiz.question`. Disconnect cancels this connection's output and turns; a turn
   cancelled by disconnect records nothing, and its retransmission continues on the
   same spent counters and deadline (`TurnBudget.for_retransmission`). A turn
   cancelled by STOP/new turn records a snapshot-only result so it cannot be revived.
8. **Context.** Canonical facts rendered verbatim from `SessionState` every decision;
   recent dialogue bounded; older dialogue compacted deterministically (no model call)
   and labelled non-authoritative; evidence/dialogue HTML-escaped inside untrusted tags.
9. **Composition.** Production registers only PostgreSQL repositories and supplied
   services; without a database every call fails closed; without an approved verifier
   authentication fails closed; unregistered model → `PROVIDER_UNAVAILABLE` for turns
   while navigation still works.

## Decisions and proposals needing owners (not settled here)

| Item | Owners | Current behaviour |
|---|---|---|
| WSS credential presentation and endpoint path | M1/M5 | Proposed bearer header + `/v1/ws`. |
| Credential issuance (PKCE flow), session-creation and source-selection HTTP routes | M1/M5/M2 | Not exposed; `IdentityService.bind_new_session`, `SessionService.create_session`/`pin_source` exist. |
| Nested model accounting in tools; 8/12/45 and revision cap | M1/M3/M4 | Nested calls recorded, not counted; 4/6/20 enforced; no revision cap. |
| Companion source (PDF + lecture) in session state | M1/M3/M5 | `ToolContext.companion_source_version_ids` exists but composition supplies none; `search_lecture` refuses out-of-scope versions. |
| `evidence_version` on resolved evidence | M2/M1/M4 | Missing → delegation refused. |
| Factual-history handoff (legacy `assessment_summaries`, `review_requested`) | M1/M4/M2/M5 | Summaries sent empty unless M4 registers a provider; `review_requested` traced and ignored. |
| Source-reading vs generated segment distinction | M1/M5 | `kind` omitted for source reading. |
| Mid-segment `progress` persistence cadence | M1/M5 | Only `completed` persisted. |
| Total binary message size | M1/M5 | Undecided; cached audio split at 32 KiB (implementation only). |
| Result-set retention | Product/M1 | No default; disabled until `NETRA_RESULT_SET_TTL_SECONDS` set. |
| Multi-process generation/turn registries | M1/M2 | In-process; needs sticky routing or PostgreSQL-backed registry. |
| Microphone upload protocol / server ASR | M1/M5 | None; only final `turn.submit` text creates turns. |
| RDS/PgBouncer vs Compose placement | M1/M2 | Unchanged. |
