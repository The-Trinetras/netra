# M1 — Coordinator, identity and session

Read [ownership](ownership.md), [current scope](../architecture/current-scope.md),
[Coordinator rules](../../.claude/rules/coordinator.md), [message flow](../architecture/message-flow.md)
and [runtime baseline](../architecture/runtime-baseline.md).

**Own:** Coordinator routing/evidence strategy, bounded tools, trusted identity
context, session mutation/versioning, handoffs, transport, cancellation and server
speech control. Identity owns access binding; Session owns reading/interaction state.
Tutor teaching belongs to M4; M2 owns persistence mechanics.

**Approved target:** route deterministic commands before reasoning. For questions,
inspect evidence, identify a specific gap and change strategy only when useful;
validate replacements or clarify/state the limitation. Select scoped context and
preserve canonical facts outside compaction. Share the existing 4/6/20 budget across
retries/fallback/Tutor. The 8/12/45 and two-revision proposal needs a decision.

**Current source evidence:** [router.py](../../api/src/netra_api/coordinator/router.py)
contains deterministic routing; [limits.py](../../api/src/netra_api/coordinator/limits.py)
contains budget tracking. [graph.py](../../api/src/netra_api/coordinator/graph.py)
raises `NotImplementedError`; [endpoint.py](../../api/src/netra_api/transport/websocket/endpoint.py)
and [dispatcher.py](../../api/src/netra_api/transport/websocket/dispatcher.py) are empty.
The [session repository](../../api/src/netra_api/session/repository.py) is a protocol,
not durable persistence. These facts do not establish a working request journey.

**Shared boundaries:** [agent schemas](../../shared/contracts/agent/v1/) with M4;
[protocol schemas](../../shared/contracts/protocol/v1/) with M5; source/evidence
resolution and repository transactions with M2; visual/video evidence with M3.
Preserve pending-question identity, source pinning, expected-version semantics and
request-ID replay-before-version-check semantics. A same-ID/different-payload
request fails closed. Never reset counters on a handoff or retransmission.

**Next integration work:** implement the bounded loop/transport and concrete service
wiring; coordinate factual-history handoff migration with M4 and video state with
M3/M5. Review budget accounting including model calls inside tools. Keep policy
choices pending without blocking independent wiring against approved contracts.

**Acceptance target:** prove insufficient evidence changes the next action, sufficient
first evidence needs no repair, unauthorized references are rejected, duplicate
requests create one effect, and STOP/reconnect never revive audio. Preserve the exact
reading position and question through failure. No application checks were run in
this documentation migration; see the [report](../audits/documentation-migration-report.md).
