# M4 — Tutor, factual history and evaluation

Read [ownership](ownership.md), [current scope](../architecture/current-scope.md),
[learning rules](../../.claude/rules/learning.md), [agent boundaries](../architecture/agent-boundaries.md)
and [runtime baseline](../architecture/runtime-baseline.md).

**Own:** Tutor explanation/adaptation, optional checks, factual activity/answer/
student-stated-reasoning/feedback/assistance history, evaluation and Neo4j projection.
Learning service validates and commits proposals; Session owns pending session
context and reading return position. No automatic labels or spaced-review scheduling.

**Approved target:** answer the study question, offer checks with consent, adapt to
observed responses and keep each attempt's assistance separately. Do not diagnose
mastery or persist inferred misconceptions as facts. “Studied — understanding not
tested” describes activity, not a new enum. Preserve an unanswered question across
reconnect without model calls while waiting; keep private answers/rubrics out of
public questions, speech and logs. Evidence must support each check and feedback.

**Current source evidence:** [Tutor run_turn](../../api/src/netra_api/learning/tutor/agent.py)
and [LearningService.propose_event](../../api/src/netra_api/learning/assessment/service.py)
raise `NotImplementedError`. [AssessmentAttempt](../../api/src/netra_api/learning/assessment/models.py)
has an answer/outcome/hint count but does not establish complete delivered activity,
reasoning, feedback and assistance persistence. Legacy status derivation/review code
remains. [Evaluation interfaces](../../evaluation/scripts/interfaces.py) are not
an integrated offline judge or verified teaching quality.

**Shared boundaries:** [agent v1 schemas](../../shared/contracts/agent/v1/) with M1
still contain legacy status-shaped summaries and `review_requested`. Coordinate a
factual-history migration, with M2 storage and M5 public presentation. Do not rename
enums or fabricate history. Existing public `quiz.question` and ordinary `turn.submit`
answer semantics remain authoritative; no new assessment platform is required.

**Next integration work:** Tutor loop and bounded service wiring, factual record
validation/commit/replay, relevant history selection, optional-check grounding criteria
and source-checked evaluation. Review obsolete status/review coupling without deleting
stores or code. Old numeric mastery/review policies are no longer pending decisions.

**Acceptance target:** correct/incorrect/alternative reasoning, misrecognized units,
transcript correction, declined checks, hint attribution, repeated attempts and
duplicate submissions. Prioritize deterministic checks and original-source review;
Prometheus-2 7B on Modal/A100 40 GB is the selected primary model judge under the
[model/evaluation plan](../architecture/model-evaluation-plan.md), outside live
execution. Own its HTTP adapter, isolated deployment, calibrated rubrics, strict
parser, resumable results and measured credit use/shutdown; coordinate hosting
with M2. Lightning AI/Kaggle are alternatives. Custom Ragas-style scripts keep
Ragas uninstalled. Hosted-evaluation completion requires live evidence. Blindfolded
sighted testing is not blind-student usability evidence. No application checks were
run here; see the [report](../audits/documentation-migration-report.md).
